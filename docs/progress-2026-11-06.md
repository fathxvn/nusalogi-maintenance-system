Alur Customer Site yang diselesaikan:

1. Detail Customer menyediakan tombol **Tambah Site**, termasuk ketika daftar masih kosong.
2. Form menampilkan nama customer sebagai identitas baca saja, dengan `site_name`, `address`, `pic_name`, dan `pic_phone`.
3. POST membuat site melalui `$customer->sites()->create(...)`. `customer_id` berasal dari model customer pada URL; payload tidak dapat memilih pemilik lain. `id` dan timestamp dari payload juga diabaikan.
4. Berhasil menyimpan mengarahkan kembali ke Detail Customer, menampilkan pesan **Site berhasil ditambahkan.**, jumlah site dan baris lokasi baru.
5. Setiap baris mempunyai aksi **Edit**. Form memuat nilai saat ini dan memakai PATCH untuk menyimpan perubahan.
6. Kedua route edit/update memakai `scopeBindings()`: site di luar relasi customer pada URL menghasilkan 404. Payload `customer_id` juga tidak dapat memindahkan site.
7. Nama site wajib, string UTF-8, maksimal 150 karakter; alamat wajib, string UTF-8, maksimal 65.535 byte; nama PIC opsional maksimal 150 karakter; telepon PIC opsional maksimal 30 karakter. PIC dapat dikosongkan. Batas alamat diperiksa berdasarkan byte, bukan jumlah karakter, sesuai kolom MySQL `TEXT`.
8. Seluruh endpoint berada dalam grup `auth` dan `role:admin` yang sama dengan Customer, dengan middleware akun aktif/disetujui yang sudah ada. Role lain, guest, admin nonaktif, pending, dan rejected diuji.

| Method | Named route | Fungsi |
| --- | --- | --- |
| GET | `admin.customers.sites.create` | Form tambah milik customer pada URL |
| POST | `admin.customers.sites.store` | Simpan site baru |
| GET | `admin.customers.sites.edit` | Form edit site milik customer pada URL |
| PATCH | `admin.customers.sites.update` | Perbarui site milik customer pada URL |

Frontend memakai `AuthenticatedLayout`, IBM Plex Sans yang diwarisi dari aplikasi, token warna semantik, `.panel`, `.table-shell`, `.soft-table`, `FormField`, `.field-control`, dan primitive Button yang sudah aktif. Form mempunyai label, error terhubung melalui ARIA, state pemrosesan, tombol simpan disabled, dan tautan Batal ke Detail Customer. Tema gelap mengikuti token aplikasi; tabel tetap dapat digulir pada layar kecil. Pengguna melaporkan QA manual Customer Site di browser berhasil pada 6 November 2026.
